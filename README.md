# Telegram-бот НАТК.Расписание
## Общая информация:

Данный бот представляет собой Telegram бота, который собирает информацию с сайта 
https://natk.ru по определённой группе и выводит расписание текущего дня.

**Стек технологий:**
* JDK 21
* Apache Maven 3.9.6
* Docker

## Информация о версии
**Версия**: ***1.1***

**Описание**:

Работает только для группы ПР-22.101. 
Для взаимодействия с ботом нужно написать слово "сегодня" в чат с ботом. 
Не зависит от регистра.

**Обновление**:

Бот сохраняет в базу данных информацию об обнаруженных парах, не дублируя её.

## Запуск бота.
**Вам  понадобится предустановленный Docker.**

***Для систем семейства Windows:***
1. В папке проекта (Natk Schedule Parser) создайте файл ```.env``` со структурой файла ```.env-EXAMPLE```;
2. Измените файл ```database.properties``` в папке ```src/main/resources/ru/der2shka/``` со структурой файла ```database.properties-EXAMPLE```;
3. Запустить файл ```windows-maven-package.bat```. Дождитесь выполнения инструкции;
4. Запустите файл ```windows-start-docker.bat```. Дождитесь выполнения инструкции.

***Для систем семейства Linux:***
1. В папке проекта (Natk Schedule Parser) создайте файл ```.env``` со структурой файла ```.env-EXAMPLE```;
2. Измените файл ```database.properties``` в папке ```src/main/resources/ru/der2shka/``` со структурой файла ```database.properties-EXAMPLE```;
3. Предоставьте права всем файдам ```linux-**.sh``` на исполнение ```chmod 777 <file-name>.sh```;
4. Запустить файл ```linux-maven-package.sh```. Дождитесь выполнения инструкции;
5. Запустите файл ```linux-start-docker.sh```. Дождитесь выполнения инструкции.

## Выключение бота.

***Для систем семейства Windows:***
1. Запустите файл ```windows-docker-down.bat```, если хотите сохранить данные из базы данных
или ```windows-docker-down-v.bat```, если хотите стереть все данные.

***Для систем семейства Linux:***
1. Предоставьте права файлам ```linux-docker-down.sh``` и ```linux-docker-down-v.sh``` на исполнение;
2. Запустите файл ```linux-docker-down.sh```, если хотите сохранить данные из базы данных
   или ```linux-docker-down-v.sh```, если хотите стереть все данные.
