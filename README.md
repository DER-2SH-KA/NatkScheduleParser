# Telegram-бот НАТК.Расписание
## Общая информация:

Данный бот представляет собой Telegram бота, который собирает информацию с сайта 
https://natk.ru по определённой группе и выводит расписание текущего дня.
Стек технологий:
* JDK 21
* Apache Maven
* Docker

## Информация о версии
Версия: 1.0

Описание:

Работает только для группы ПР-22.101. 
Для взаимодействия с ботом нужно написать слово "сегодня" в чат с ботом. 
Не зависит от регистра.

## Запуск бота.
Вам  понадобятся предустановленные Apache Maven и Docker.

Для систем семейства Windows:
1. В папке проекта (Natk Schedule Ptser) создайте файл .env со следующим содержимым:

```TELEGRAM_TOKEN=<ваш_токен_бота>```
2. Запустить файл windows-maven-package.bat. Дождитесь выполнения инструкции; 
3. Запустите файл windows-start-docker.bat. Дождитесь выполнения инструкции.

Для систем семейства Linux:
1. В папке проекта (Natk Schedule Ptser) создайте файл .env со следующим содержимым:

```TELEGRAM_TOKEN=<ваш_токен_бота>```
2. Предоставьте права файлам linux-maven-package.sh и linux-start-docker.sh 
на исполнение;
3. Запустить файл linux-maven-package.sh. Дождитесь выполнения инструкции; 
4. Запустите файл linux-start-docker.sh. Дождитесь выполнения инструкции.
